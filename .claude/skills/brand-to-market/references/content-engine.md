# 콘텐츠 엔진: 2026년 알고리즘과 크리에이터 중심 런치

조사일 2026-11-04. 플랫폼 발표와 2차 자료가 섞여 있다. 수치는 참고용이고 원칙은 안정적이다.

## 1. 지금 알고리즘이 미는 것 / 억제하는 것

| 미는 것 | 억제하는 것 |
|---|---|
| 직접 찍거나 디자인하거나 의미 있게 편집한 **오리지널** (인스타 2026-04-30 정의) | 워터마크 리포스트, 동일 영상 복제 (원본만 추천) |
| 시청 지속·완주, 스킵 안 당하는 첫 2초 | 양산형 템플릿, 같은 훅 반복 (틱톡 '오리지널리티' 신호, 2차) |
| DM 공유·저장 (도달 대비 공유) | 좋아요 구걸·감정 조작형 |
| 소규모 계정에도 새 시청자 테스트 배포 → 작은 계정도 기회 | 협찬 미고지 (영상 내 고지 요구 방향, 2차) |
| 네이티브로 올린 AI 영상 (기만적이지 않으면 오리지널로 취급) | AI 티 나는 모핑·손/텍스트 오류·과도한 매끈함 |
| 유튜브 쇼츠 2025-10 "독창성" 업데이트: 자체 해설·편집·스토리 | 클립 짜깁기 |

적용: 크리에이터와 브랜드 모두 **제품을 실제로 쓰는 장면을 직접 찍은 것**이 가장 안전하고 잘 퍼진다.
AI 생성 영상은 패키지·텍스처·세계관 컷에 쓰고, 사용 장면은 가능하면 실촬영(또는 `01` 팬캠 스킬의 "폰카 리얼리즘" 톤)으로.

## 2. 크리에이터 시딩이 중심 (브랜드 계정은 보조)

- 마이크로(1~5만) 30~50명 + 미드(5~30만) 5명. 선정 기준: 우리 타깃과 댓글 톤이 같고, 최근 30일 영상 중 제품 영상의 조회수가 평균을 넘는 사람.
- 조건: 무상 제공 + 어필리에이트(틱톡샵/쿠팡파트너스/자사몰 코드) 우선, 고정비 협찬은 지표 확인 후.
- 브리프는 한 장: 제품 한 문장, 말해도 되는 표현 목록(클레임 매트릭스 요약), 금지 표현, 영상 내 협찬 고지 문구, 결제 링크, 촬영 추천 장면 3개. 대본은 주지 않는다(오리지널 신호 보호).
- 2026년 관찰: 시딩 영상은 수백만, 브랜드 계정은 수천 조회(2차). 브랜드 계정은 **증거 보관소**로 운영: 성분·사용법·리뷰 리포스트(원본 크리에이터 콜라보 태그로, 리포스트 억제 회피)·창업자 Q&A.

## 3. 광고 앵글 7종 → 3종 제작 (영상의 7가지 아이디어를 구조화)

| 앵글 | 첫 2초 | 마지막 3초 |
|---|---|---|
| 문제 공감형 | 타깃의 불만 장면 그대로 | "링크에서 ○○원" |
| 성분/기전 스토리 | 원료 클로즈업 + "왜 이걸 넣었나" | 성분표 + 결제 위치 |
| 텍스처 ASMR | 제형 소리·발림 | 용량·가격 |
| 비교 실험 | 기존 대안 vs 우리, 같은 조건 | 차이 한 줄 (사실만) |
| 파운더 스토리 | "제가 이걸 만든 이유는" | 첫 100명 혜택 |
| 캐릭터/유머 | 브랜드 캐릭터의 상황극 | 캐릭터가 결제 버튼 가리킴 |
| 클래식 뷰티컷 | 하이엔드 광고 톤 (`07` 스킬) | 로고 + 채널 |

선택 규칙: 문제 공감형은 항상 포함. 나머지 2개는 히어로 SKU의 "콘텐츠 적합성" 점수가 높았던 이유(텍스처? 변화? 스토리?)에 맞춘다.
각 앵글은 9:16 15~30초, 훅 3종 변형으로 A/B. 제작은 `13-ai-influencer-brandfilm` 또는 Higgsfield `ads_studio_generate`.

## 4. 30일 런치 캘린더 (07-content-plan-30d.md)

- D-14~D-1: 크리에이터 발송(도착 D-7), 브랜드 계정에 "만드는 과정" 5편(원료·샘플·패키지·실패·확정), 대기자 명단 랜딩.
- D-day~D+7: 크리에이터 영상 공개 집중(같은 주에 몰아야 알고리즘·검색이 겹친다), 광고 3앵글 × 훅 3종 소액 테스트, 첫 100명 리뷰 이벤트.
- D+8~D+21: 지표로 살아남은 앵글·크리에이터에 예산 집중, 리뷰 리포스트(콜라보 태그), FAQ 영상(댓글 질문 그대로), 번들 출시.
- D+22~D+30: 결산 영상(판매 수·리뷰·실패), 2번째 크리에이터 웨이브, 다음 SKU 투표(댓글 참여 신호).

주간 고정: 월 증거(성분/테스트), 수 사용 장면, 금 리뷰/Q&A. 하루 1편 이상은 크리에이터 콘텐츠가 대신 채운다.

## 6. 한국 × 글로벌 동시 운영 메모
- 같은 영상을 두 언어 자막으로 올리되 계정은 국가별 분리(검색·추천 모두 지역 신호가 강함).
- 한국은 네이버 검색 유입이 크므로 블로그·지식인 톤의 성분 설명 글과 스마트스토어 상품명 최적화를 병행.
- 글로벌은 틱톡 → 아마존/틱톡샵 검색으로 이어지는 "이름 검색" 경로를 만들기 위해 영상에서 브랜드명을 소리 내어 말하게 한다.
