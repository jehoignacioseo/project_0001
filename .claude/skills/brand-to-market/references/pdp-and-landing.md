# 상세페이지(PDP)·랜딩·이미지 일관성

## 1. 이미지 일관성 프로토콜 (영상의 "흰 배경 다각도 컷"을 규칙으로)

1. 컨셉 시안 4종은 무드가 분명히 다르게 (예: 보태니컬 / 클리니컬 / 미니멀 모노톤 / 플레이풀 컬러). 사용자가 하나를 고른다.
2. 확정 즉시 **마스터 세트** 생성: 정면, 좌우 45도, 측면, 후면(표시사항), 뚜껑 열림/제형 노출, 손에 든 스케일 컷. 흰 배경, 같은 조명.
3. 마스터 세트를 레퍼런스 보드 한 장으로 묶는다(`09-ai-influencer-refboard`). Higgsfield를 쓰면 제품을 Element/Soul로 저장.
4. 이후 모든 히어로컷·연출컷·영상 프레임 생성에 보드를 첨부하고 "용기 형태·색·라벨 위치·브랜드명 글자 유지"를 프롬프트에 명시.
5. 패키지 위 텍스트는 클레임 매트릭스를 통과한 문구만. 생성 이미지의 글자 깨짐은 후보정 또는 HTML 오버레이로 처리.
6. 영상(`13-ai-influencer-brandfilm`)도 같은 보드에서 시작한다. 제품이 장면마다 달라 보이면 그 컷은 버린다.

## 2. 히어로·상세 이미지 샷리스트 (최소 세트)

| 용도 | 컷 | 비율 |
|---|---|---|
| 랜딩 히어로 | 제품 + 핵심 원료/텍스처 + 한 문장 약속 | 16:9, 9:16 |
| 피드/스토어 썸네일 | 제품 단독, 밝은 배경 | 1:1, 4:5 |
| 텍스처 | 제형 클로즈업(스와치, 발림) | 1:1, 9:16 |
| 사용 장면 | 타깃 인물이 실제 상황에서 사용 (`02` 룩북 / `07` 뷰티광고) | 4:5, 9:16 |
| 성분/기전 | 인포그래픽(텍스트는 HTML로) | 1:1 |
| 비교 | 기존 대안 vs 우리 (사실 기반, 비방 금지) | 4:5 |
| 패키지 표시사항 | 후면 라벨 실사 | 1:1 |
| 번들 | 구성품 플랫레이 | 1:1, 4:5 |

## 3. 전환 구조 PDP (06-pdp-copy.md)

모바일 첫 화면 안에 1~3번이 보여야 한다. 각 섹션은 **한 문장 헤드라인 + 증거 한 줄 + 이미지 지시**로 쓴다.

1. 훅: 타깃의 불만을 그 사람의 말투로 (리뷰에서 가져온 실제 표현)
2. 약속: 포지셔닝 한 문장
3. CTA(가격·구성·배송 소요일)
4. 증거: 성분/기전/테스트 (클레임 매트릭스 "가능" 열만)
5. 사용 장면 3컷
6. 비교: 기존 대안과의 차이 3가지 (사실, 수치는 출처)
7. UGC/리뷰: 실제 리뷰만. 런치 전이면 "첫 100명 리뷰 이벤트" 블록으로 대체
8. 텍스처/제형 클로즈업
9. 사용법 (언제·얼마나·무엇과 함께)
10. FAQ 5개 (배송, 환불, 민감 피부/알레르기, 보관, 성분 출처)
11. 보증·환불 정책, CS 채널, 응답 시간
12. 창업자 한마디 (얼굴 공개 가능 시 사진, 아니면 손글씨/서명 톤)
13. 가격·번들 재제시 + CTA + 신뢰 배지(등록·인증·결제 수단)

카피 규칙
- 모든 문장은 `02-claims-matrix.md`의 해당 국가 열을 통과해야 한다. 통과 못 하면 대체 표현으로 바꾼다.
- 숫자는 출처 또는 자체 테스트 조건을 함께 쓴다.
- 영어 버전은 번역이 아니라 재작성: 미국은 성분 투명성·리뷰·배송 신뢰, 일본은 사용감·안전·정중함, 한국은 성분 등급·가성비·비교.

## 4. 랜딩 페이지 (자사몰/Shopify/Higgsfield create_website)

- PDP 13섹션을 그대로 쓰되 상단 고정 CTA, 하단 고정 "구매하기" 바. 결제는 실제 채널(스마트스토어/Shopify/틱톡샵)로 연결하거나 자체 결제.
- 속도: 이미지 WebP, 첫 화면 200KB 이하. 텍스트는 이미지에 굽지 않는다(한글·영문 깨짐 방지, 검색 노출, 번역 용이).
- 필수 법적 블록: 사업자 정보, 이용약관·개인정보, 교환·환불, 화장품 표시사항 전문(전성분).
- 추적: 메타 픽셀·틱톡 픽셀·GA4, UTM으로 크리에이터별 매출 측정.
