# 벤치마크 DNA — "AI 도구 단계형 튜토리얼 + 댓글 키워드 DM" 캐러셀 (2026-10-19)

레퍼런스: AI 자동화 빌더 계정의 9컷 캐러셀 「월 1000만원 버는 유튜브 채널 만드는 법 — 클로드 Opus 5.5로 굴리는 유튜브 자동화」
게시 4일 차 지표(스크린샷 실측): 좋아요 332 · **댓글 1,173** · 공유 41 · 저장 다수(저장됨 탭에서 캡처)

> ⚠️ **브랜드명 격리**: 레퍼 계정의 핸들, 픽셀 로봇 마스코트, "게으른 빌더" 사인오프, 그리고 레퍼가 소개한
> 구체 도구 조합·수치(RPM, 정산 금액)는 우리 산출물에 **절대 옮기지 않는다.** 빌리는 것은 구조·결·CTA 역학뿐이다.

## 왜 이 포맷이 지금 밀리는가 (핵심 인사이트)

1. **댓글이 좋아요의 3.5배.** 2026년 인스타그램 추천 알고리즘은 좋아요보다 **댓글·공유·저장·DM** 같은 "비용이 드는 반응"을 도달 신호로 더 크게 친다. 이 캐러셀은 마지막 컷에서 "댓글에 '유튜브'라고 남기면 가이드를 DM으로" 라는 **댓글 키워드 → DM 자동 발송(리드 마그넷)** 장치를 써서 댓글 1,173개를 만들었다. 댓글이 터지면 탐색탭·릴스 추천으로 재배포된다.
2. **"결과 숫자 + 반대급부 제거"** 훅. "월 1000만원" (결과) + "카메라 없이" (가장 큰 진입 장벽 제거) 를 한 화면에 둔다. 독자의 첫 반론을 훅 단계에서 무력화한다.
3. **단계형(1단계~5단계) 구조는 저장을 만든다.** 각 컷이 "도구 + 하는 일 + 한 줄 결과" 한 세트라서, 나중에 따라 하려고 저장하게 된다. 캐러셀 완주율도 올라간다(단계 번호가 진행 욕구를 만든다).
4. **도구 UI 목업 스크린샷**. 실제 제품 화면(브라우저 창, 설정 패널, 폰 UI)을 일러스트로 재현해 "진짜 돌아간다"는 신뢰를 준다. 사진이 아니라 **크림 배경 위 브라우저 프레임 일러스트**라 톤이 전 컷 통일된다.
5. **매 컷 "밀어서 보기 →" 버튼**. 스와이프 유도를 마지막 컷 직전까지 반복한다. 하단 진행 바 위의 마스코트가 컷마다 오른쪽으로 이동해 "몇 장 남았는지"를 보여준다.
6. **2번 컷은 '대부분이 망하는 이유'**. 훅 직후 "X vs ○" 비교 수치(저단가 vs 고단가)로 독자의 기존 선택을 틀렸다고 말한다 → 끝까지 보게 하는 긴장.
7. **마지막 직전 컷은 '결과는 이겁니다'**. 폰 UI(발행 일정표)로 결과를 **시각화**하고 "내가 할 일: 없음 / 자동" 손글씨 스티커로 정서적 마무리.

## 8축 DNA

| 축 | 관찰 (근거: 스크린샷) |
|---|---|
| 1. 비주얼 | 크림 `#F3EDE2`(추정) 배경 + 다크 브라운 `#2B2320` 본문 + **테라코타 `#C4673A`** 액센트. 따뜻한 저채도. 사진 0장, 전부 플랫 일러스트와 UI 목업. 구석에 작은 점·별 장식. |
| 2. 타이포 | 초굵은 산세리프(Pretendard/Black Han 계열) 2줄 헤드라인, **센터 정렬**. 핵심 단어는 테라코타 색 또는 형광 밑줄 하이라이트("월 1000만원", "몇 배", "결과"). 서브카피는 테라코타 1줄. 손글씨 메모("여기서 망해요", "하루 한 편씩", "바로 보내드릴게요")를 보조 레이어로. |
| 3. 구도 | 상단 `@핸들` → 소형 라벨 pill("유튜브 자동화") → 헤드라인 → **중앙 큰 목업(브라우저/폰 프레임)** → 하단 설명 2줄 → 우하단 "밀어서 보기 →" 테라코타 pill → 최하단 진행 바(점 9개 + 마스코트 위치). 전 컷 레이아웃 상수. |
| 4. 콘텐츠 기둥 | ① 수익형 자동화 워크플로 ② 도구 연결 튜토리얼(MCP·커넥터) ③ 수익 구조 해설(RPM) ④ 결과 증빙 ⑤ 리드 마그넷(가이드·프롬프트 원문·세팅) |
| 5. 포맷 | **9컷 캐러셀 고정**, 4:5. 구조: 훅(1) → 문제/비교(2) → 1~5단계(3~7) → 결과(8) → 댓글 CTA(9). |
| 6. 캡션 보이스 | 첫 줄이 훅 반복("월 1000만원 버는 유튜브 채널은 만들고 싶은…") → 더 보기로 접힘. 존댓말 구어체, "~해요/~합니다" 혼용. |
| 7. 해시태그 | 캡션 하단 추정(스크린샷 미확인 → **추정**). |
| 8. 리듬 | 컷마다 목업 종류를 바꿔(검색 결과 그리드 → 채팅 UI → 설정 패널 → 영상 생성기 → 타임라인 → 폰 일정표) 지루함을 끊되, 배경·폰트·pill·진행 바는 고정. |

**한 줄 DNA:** 크림+테라코타 플랫 일러스트 위에 "결과 숫자 + 장벽 제거" 훅 → 단계별 도구 목업 → 결과 시각화 → **댓글 키워드 DM** 으로 닫는, 저장과 댓글을 동시에 뽑는 튜토리얼 캐러셀.

## 컷 템플릿 (앱 프롬프트에 반영됨)

| # | 역할 | 구성 |
|---|---|---|
| 1 | 훅 | `[결과 숫자] + [대상]` 헤드라인 2줄 + 테라코타 서브카피(쓰는 도구/방법 한 줄) + 말풍선 "~없이" (반대급부 제거) |
| 2 | 문제/비교 | "대부분 여기서 망합니다" — 나쁜 선택 ✗ vs 좋은 선택 ✓ 수치 대비 |
| 3~7 | N단계 | kicker `1단계 — ○○`. 도구 UI 목업 + 하단 2줄: 이 단계에서 **무엇을 넣으면 무엇이 나오는지** |
| 8 | 결과 | "결과는 이겁니다" — 결과를 UI/표로 시각화 + "내가 할 일: 없음" 류 정서 스티커 |
| 9 | 댓글 CTA | "○○ 가이드 필요하세요?" → 댓글에 **키워드 한 단어** → DM으로 보내는 것 3가지 체크리스트 → 계정 사인오프 |

## 캡션 공식

```
[훅 변주 한 줄 — 캐러셀 1컷과 다른 각도]  ← 첫 줄이 전부
(빈 줄)
[왜 이게 되는지 2~3문단, 1~2문장씩 줄바꿈]
(빈 줄)
💬 댓글에 "[키워드]" 남기면 [리드 마그넷]을 DM으로 보내드릴게요
📌 나중에 따라 하려면 저장
```

## 앱 반영 내역

- 슬라이드 테마 `warm` (웜 튜토리얼): 크림+테라코타, 상단 `@핸들`, 라벨 pill, 센터 정렬, 매 컷 "밀어서 보기 →", 하단 진행 점.
- 캐러셀 프롬프트: 소재가 방법·도구·워크플로형이면 **단계형 9컷 구조**를 쓰고, 훅은 "결과 숫자 + 장벽 제거"로 쓴다.
- 설정 `ctaMode: comment` + `leadMagnet`: 마지막 컷과 캡션을 **댓글 키워드 → DM** 구조로 생성. 생성 결과에 `commentKeyword`가 담긴다(ManyChat 등 자동 DM 도구의 트리거 단어로 그대로 사용).
