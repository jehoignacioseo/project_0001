# OPEN_QUESTIONS

M0·M1을 구현하며 사양이 정해지지 않았던 지점들이다. 임의로 추정하지 않고
여기에 적은 뒤 **기본값으로 진행**했다. 각 항목에 "지금 어떻게 해뒀는지"와
"바꾸려면 어디를 고치면 되는지"를 함께 적는다.

기준일: 2026-08-18 · 범위: M0, M1

---

## 1. 이 저장소와 기존 앱의 관계

`project_0001`에는 이미 `insta-content-studio`(Next.js)가 있다. Carousel Forge는
같은 문제를 훨씬 넓게 다루므로, 흡수인지 대체인지 공존인지가 정해져 있지 않다.

- **기본값**: 기존 앱을 건드리지 않고 `carousel-forge/` 하위에 독립적으로 만들었다.
- 통합 방향이 정해지면 `apps/web`(M8)에서 기존 UI 자산을 가져올 수 있다.

## 2. 중국어 폰트가 아직 임베드돼 있지 않다

Pretendard(한/영)만 `core/render/fonts/`에 들어 있다. Noto Sans SC는 파일이
크고 M7(샤오홍슈·중국어) 전에는 렌더에 쓰이지 않는다.

- **기본값**: `scripts/fetch_fonts.py --set zh`는 지금은 라이선스 파일만 받는다.
  중국어 세트를 실제로 쓰려면 `core/render/model.py`의 `FONT_FILES`에 등록해야 한다.
- 등록되지 않은 폰트를 쓰려 하면 렌더가 조용히 대체 폰트로 넘어가지 않고 실패한다.

## 3. Figma가 로컬 폰트를 못 찾을 때의 동작

SVG는 `font-family` 이름으로 **보는 사람 컴퓨터의 폰트**를 찾는다. Pretendard가
설치돼 있지 않으면 Figma가 임의로 대체하면서 줄바꿈이 달라진다.

- **기본값**: 내보내기 ZIP의 `04_reference/fonts/`에 폰트를 동봉하고, `README.md`에
  "먼저 폰트를 설치하라"를 첫 단계로 적었다. `manifest.json`의 `fonts_required`에도
  같은 정보가 들어 있다.
- M6 플러그인 경로에서는 `figma.loadFontAsync` 실패를 잡아 사용자에게 알릴 수 있다.
  SVG 드래그앤드롭 경로에는 그런 훅이 없다.

## 4. text-transform을 SVG에 어떻게 실을 것인가

StyleDNA의 `case: upper`는 CSS `text-transform`으로 렌더된다. 화면에는 대문자,
DOM에는 원문이 남는다.

- **기본값**: **화면에 보이는 글자**(변환된 텍스트)를 SVG와 manifest에 싣는다.
  그래야 PNG와 어긋나지 않는다.
- 대안: 원문을 싣고 Figma `textCase = 'UPPER'`로 재현. 편집 시 원문이 보존되는
  장점이 있으나 SVG 경로에는 대응 속성이 없다. 어느 쪽이 편집 경험에 나은지 미정.
- **부작용**: `emphasis_spans`의 인덱스는 원문 기준이다. 한국어·영문 대소문자
  변환은 길이가 보존되지만, 길이가 변하는 문자(예: ß → SS)가 들어오면 인덱스가
  어긋난다. 현재 대상 언어(ko/zh/en)에서는 발생하지 않는다.

## 5. SVG 경로에서 텍스트를 길게 고치면 줄바꿈이 따라오지 않는다

SVG의 각 줄은 실측 좌표가 박힌 `<tspan>`이다. Figma에서 문구를 늘리면 그 줄만
길어지고 자동으로 다음 줄로 넘어가지 않는다.

- **기본값**: 이 한계를 `README.md`에 적지 않았다 — 대신 **플러그인 경로(M6)를
  권장 경로로 안내**한다. 플러그인은 TextNode에 전체 문자열과 폭을 주므로 Figma가
  스스로 줄바꿈한다.
- SVG 경로는 "가볍게 문구 다듬기"용, 플러그인 경로는 "제대로 편집"용으로 나뉜다.

## 6. 배경 이미지 위 대비 검증이 아직 픽셀 기반이 아니다

`core/render/geometry.py`는 WCAG 대비비와 스크림 합성 계산을 제공하지만, 배경이
사진일 때 **텍스트 뒤 실제 픽셀 휘도**를 샘플링하지는 않는다.

- **기본값**: M1은 안전영역 침범(기하)만 판정한다. 대비 판정은 A8/A9가 붙는 M4의 일이다.
- 그때 필요한 것: 렌더 페이지에서 각 텍스트 박스 영역의 평균/최악 휘도를 캔버스로
  샘플링하는 측정 항목 추가.

## 7. 캔버스 variant가 데이터 모델에 없다

`RenderSet.canvas_variant`로 `square` 같은 대체 캔버스를 고를 수 있지만,
`CarouselSet` 테이블에는 대응 컬럼이 없다.

- **기본값**: 항상 플랫폼 기본 캔버스를 쓴다. variant를 실제로 노출할 때
  마이그레이션을 하나 더 얹는다.

## 8. platforms.yaml의 수치는 사람이 확인해야 한다

`scripts/validate_platforms.py`는 **형태**(비율 일관성, 범위, 필수 필드)만 본다.
1080×1350이 오늘의 인스타그램 규격이 맞는지는 검증하지 못한다.

- **기본값**: `_meta.verified_at`에 확인일을 적고, 180일이 지나면 `/healthz`와
  검증 스크립트가 경고한다. 갱신은 사람이 각 플랫폼 문서를 보고 한다.

## 9. 업로드용 이미지 기본 포맷이 JPG다

`platforms.yaml`의 `export_format` 첫 항목이 쓰인다. 인스타그램은
`["jpg", "png"]`이라 기본이 JPG(품질 95)다.

- **기본값**: JPG. 파일이 작고 업로드가 빠르다.
- 무손실이 필요하면 `export_format` 순서를 뒤집으면 된다. 코드 변경은 필요 없다.

## 10. `summary` role은 스펙 본문이 아니라 부록 B에만 있다

섹션 3.2의 `slide_roles_sequence` 예시에는 없지만 부록 B의 role 표에는 있고,
A4가 "마지막 직전에 저장 유발 요약본"을 배치하라고 요구한다.

- **기본값**: 스키마의 `SlideRole` enum에 포함시키고, 레이아웃은 `point` 템플릿에
  매핑했다. 요약 전용 템플릿이 필요하면 M4에서 4번째 템플릿을 추가한다.

## 11. Playwright 브라우저 리비전이 환경과 어긋난다

이 환경에는 Chromium 1194가 깔려 있고 playwright 1.62는 1234를 기대한다.

- **기본값**: `core/render/html_renderer.chromium_executable()`이
  `PLAYWRIGHT_BROWSERS_PATH`의 실행 파일을 직접 찾아 쓴다.
  `CAROUSEL_FORGE_CHROMIUM`으로 명시 지정할 수도 있다.
- CI에서는 브라우저 리비전을 고정해야 렌더 결과가 재현된다. 조판 엔진이 바뀌면
  실측 좌표도 미세하게 달라진다.

## 12. 출력 배율(device scale factor)이 1로 고정돼 있다

`SlideRenderer(device_scale_factor=...)`로 바꿀 수 있으나 파이프라인은 1을 쓴다.

- **기본값**: 1080×1350 실측 픽셀. 플랫폼 규격 자체가 그 크기라 업스케일이
  이득인지 불분명하다. 2x가 필요하다는 근거가 나오면 그때 올린다.

## 13. 폰트 재배포의 법적 검토

Pretendard는 SIL OFL 1.1이라 임베드·재배포가 가능하고, 내보내기 ZIP에
`Pretendard-LICENSE.txt`를 함께 넣는다.

- **기본값**: 동봉한다. 다만 결과물이 외부 사용자에게 전달되는 형태이므로
  실제 서비스 전에 법무 확인을 권한다. OFL이 아닌 폰트는 절대 동봉하지 않는다
  (절대 규칙 #10).

## 14. 폐기본 보존의 범위

절대 규칙 #9는 "모든 생성물은 DB에 남긴다(폐기본 포함)"이다.

- **기본값**: `Asset.is_discarded`/`discard_reason`과 `GenerationLog`로 **레코드**를
  남기고, `storage/` 실물 파일은 `.gitignore`에 넣었다(버전 관리 대상이 아님).
  파일 보존 기간·용량 정책은 정해지지 않았다.

## 15. 픽셀 대조에서 남는 1% 차이

`scripts/verify_render.py`가 PNG와 SVG 래스터를 비교하면 글자 영역에서 약 1%의
픽셀이 다르게 나온다.

- **원인**: 서브픽셀 안티에일리어싱과 JPEG 압축. 정수 픽셀 이동 탐색에서 9장 모두
  최적 이동이 `(0,0)`이므로 좌표가 밀린 것은 아니다.
- **기본값**: 불일치 비율 상한 2.5%, 그리고 **최적 이동이 (0,0)이 아니면 실패**.
  후자가 좌표 회귀를 잡는 진짜 지표다.
