# 촬영 가이드 (사용자용, 한 장)

## 매일 받는 미션 메모 형식
```
Day 05 · S1 #05 뚱바 라떼
살 것: 바나나우유(뚱바) 1, 캔 에스프레소 1, 빨대
찍을 컷: ①입구 ②집는 손 ③가격표 ④섞는 과정(소리!) ⑤첫 모금 ⑥빈 병
예상 비용: 3,400원 / 예상 촬영 시간: 8분
```

## 공통 규칙
- **세로(9:16)**, 폰 기본 카메라, 1080p 이상, 60fps면 더 좋음.
- 컷당 8~15초. 짧게 여러 개가 길게 한 개보다 편집에 유리.
- **소리가 절반**: 봉지 뜯는 소리, 뚜껑, 면 빨아들이는 소리. 매장 BGM이 크면 조리 컷은 밖이나 집에서.
- 가격표는 **반드시** 한 컷. 글자가 읽히게 1초 정지.
- 손이 나오는 컷은 손톱·소매 깔끔하게. 얼굴 노출은 선택.
- 조명: 매장 형광등은 OK. 집 조리 컷은 창가 또는 책상 스탠드 하나를 음식 옆 45도에.
- 흔들림: 팔꿈치를 몸에 붙이고 천천히. 줌 대신 가까이 가기.
- 첫입 컷은 **리액션 1초**(눈 커지기, 고개 끄덕) 넣으면 완주율이 오름.
- 실패 컷(쏟음, 터짐)은 지우지 말고 같이 보낼 것. 가장 잘 도는 소재.

## 전달 방법
- 원본을 날짜 폴더로 묶어 Google Drive에 업로드(연결돼 있음). 폴더명 `YYYY-MM-DD_S1-05`.
- 올린 뒤 한 줄만: "Day 5 올림. 맛 8점, 다시 살 듯, 커피가 너무 셌음." 이 한 줄이 자막 코멘트가 됨.

## 주말 길거리 음식(S2) 추가 규칙
- 만드는 과정이 메인: 철판·기름·반죽 클로즈업 각 10초.
- 사장님 촬영 허락 한마디("쇼츠용으로 조리 과정만 찍어도 될까요?"). 얼굴은 안 찍음.
- 한 번 나가서 4~5개 메뉴. 메뉴마다 ①조리 ②가격 ③첫입 3컷이면 충분.
